## 개발·검사 이력

1. 인증 첫 검사에서 201 기대에 401을 받아 미구현 상태를 확인하고 구현 후 통과했다.
2. 게시글 첫 검사에서 요청 경로 미구현을 확인하고 작성자 권한 구현 후 통과했다.
3. 첫 E2E 24개 중 22개 통과, 수정 화면 textarea의 라벨 조회로 2개 timeout. 라벨과 입력을 분리한 뒤 24개 통과했다.
4. 각 사례의 세션 초기 상태까지 보장하도록 beforeEach에 앱 재기동을 추가했다. 이는 검사 준비 보완이며 독립 개발 반복을 추가한 것이 아니다.
5. npm 설치 과정의 동시 실행과 파일 누락으로 린터가 실패했다. 단일 설치와 버전 고정 후 lint·build를 검증했다. 남은 감사 경고는 docs/review.md에 기록했다.
6. 모니터링의 5xx 시계열이 없는 경우 오류율 패널이 No data를 표시했다. 전체 요청 시계열이 존재할 때만 0을 표시하도록 쿼리를 수정했다.
7. 초기 재사용 하네스 문서 전문은 로컬에 복사하지 않았다. 요구 명세 3개의 보존 사본은 구현 후 생성했으므로 사전 동결 준수를 주장하지 않는다.
